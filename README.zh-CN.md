# DSH ChatGPT 直连插件

ChatGPT Codex 多账号、额度、真实 Fast、持久请求日志和纯内存鹈鹕 PNG 测试。无需 CLIProxyAPI。要求 DSH **0.2.2-rc.1+**、Node **22.19.0+**。

通过 DSH Market 从 [GitHub 仓库](https://github.com/M4rkzzz/dsh-cpa)安装，或安装打包归档。默认分支的版本更新即可被 GitHub 来源检测，不依赖 GitHub Release。

## 每账号鹈鹕测试

账号下的 **鹈鹕测试** 四字是单次执行按钮；运行时可停止。下拉只有「不自动执行、5 分钟、10 分钟、20 分钟、30 分钟」，只保存计划，**选择后不立即执行**。恢复或重新设置计划后也先等完整间隔，不补跑；每账号单飞，完成后再计下一间隔。

切换会暂停旧账号的自动测试但保留其 PNG 和计划；切回后重新等待完整间隔。停用账号不能发起测试或 CPA 模型请求，也不轮询切号。旧账号若仍有普通会话请求，须先停止后才能切换或移除。

固定提示词：

> 生成一张鹈鹕骑自行车的SVG

测试会消耗真实模型额度。使用该账号明确选定的模型，无会话、工具或附件；单次含验证、生成、转换最多 120 秒，输出最多 256 KiB。后台将受限 SVG 转为 PNG，立即丢弃 SVG，历史只保留 PNG 和必要的图片元数据，不生成图片或测试转录文件。

「历史」打开当前账号的 PNG 图片。每账号最近 8 张，全局最多 64 张 / 16 MiB，单图最多 2 MiB；重载清空图片但不清空设置或日志。使用一个受控 WASM worker，拒绝脚本、实体、外部/本机资源、嵌入图片和过高复杂度。转换失败不伪造成功图片。

## 日志

只记录插件加载后的新 CPA Codex 与原 `openai-codex` 请求，不扫描或重放历史会话；不把额度、模型目录 HTTP 查询算成模型请求。

日志以追加式 NDJSON 文本保存在当前 profile 的 `.dsh-cpa/activity.ndjson`，**不设自动条数或容量上限**。仅保存页面展示的信息：开始时间、账号邮箱、来源、模型/通道、结果/终止原因、安全错误码、真实 HTTP 状态、缓存读写和命中率、Token、TTFT、耗时、TPS、标准价格参考金额与服务等级证据。不保存结束时间、提示词、回复、思考、工具参数、会话标识、凭据或原始错误。

页面按 50 条分页，可筛选、流式导出、手动清空；常驻内存不随历史增长。文本单条通常数百字节到约 1 KB，但长期无限累计仍会占用磁盘。日志在重启后保留；清空不删除账号或 PNG，也不取消正在运行的普通会话。

时间只展示开始时间：本地当天 `HH:mm`，其他日期 `MM-DD`；完整开始日期可从提示查看，不展示结束时间。

### 指标与金额

- Input 是完整输入（已含缓存）；缺失字段保持未知，不能用宿主默认的零值反推「缓存为 0」或「免费」。均值、Token 合计和金额显示已知样本覆盖。
- TTFT 是本机从迭代开始到首个文本/推理/工具增量的观测；TPS = 输出 Token ÷ 首 Token 后到终止的秒数，不冒充服务端精确解码速度。
- CPA 使用 SSE，可采集真实响应 HTTP 状态和原始用量；原宿主通道未提供的指标仍显示 `—`，绝不凭成功猜 HTTP 200。
- 美元为 [OpenAI Standard API 官方价格](https://developers.openai.com/api/docs/pricing)的静态参考折算，核对日期 **2026-11-08**，**不是 ChatGPT 订阅账单，也不含 Fast/Priority 加价**。请求 priority 不等于服务端确认 priority。未知型号或用量不全不按零计费；可靠上限用 `≤` 标记。

## 更新与安全

所有旧版后端入口继续保留为直达当前实现的兼容模块，避免宿主缓存旧入口时再次激活失败；旧客户端资源也保留供尚未刷新的页面使用。升级后检查实际接口并刷新页面，不凭 Market 标签宣称恢复，无需删除凭据或其它插件。

HTTP 路由仍由宿主鉴权，POST 使用真实 Host Connection 桥接协议与 Host 做同源校验，不信任转发头；图片与 JSON 均不缓存。浏览器不接收令牌，也不接收可执行 SVG。

模型同步只给相应 CPA 账号增补可信目录，不覆盖宿主默认模型或现有通道。兼容版本最低 `0.165.0`；可读取本机 Codex 缓存中的公开 `client_version`，但不导入其身份、模型或凭据。
