# DSH ChatGPT 直连插件

在 DSH 进程内完成 ChatGPT Codex 授权、模型同步、额度展示、请求日志和轻量定时 SVG 测试。直连使用 DSH 自带的 `llm-pi-ai/openai-codex`，无需本地 CLIProxyAPI 服务。

通过 DSH Market 从 [GitHub 仓库](https://github.com/M4rkzzz/dsh-cpa)安装，或安装打包归档。GitHub 来源的 Market 更新检测使用默认分支的版本号，不要求创建 GitHub Release。在「设置 → CPA」添加账号。模型同步只增补账号目录条目，保留现有模型与默认选择；会话选择 `openai-codex` 模型后走直连，原 `chatgpt-cpa` 会话在主动切换前维持原路由。

## 0.2.5：热更新修复

保留旧版后端入口，兼容宿主仍持有的旧解析路径，修复 0.2.4 热更新时旧入口缺失造成的激活失败。修正 Host Connection 内部桥接地址下的 POST 同源校验，仍使用宿主可信协议和 Host，不放宽认证或信任转发头。纯文本 HTTP 错误现在保留状态码，页面减少重复标签与说明。

若 0.2.4 曾升级失败，安装修复版后须确认插件实际激活并刷新页面；“文件已更新”或 Market 的“已加载”标签不能单独证明接口已恢复。无需删除账号、凭据或其它插件。

## 请求日志与统计

仅观测**插件加载之后的新 `openai-codex` LLM 请求**，包括普通请求和鹈鹕测试；不扫描历史会话，不包含其他供应商、额度查询或模型目录查询。

- 最近 200 条：时间、来源、请求状态、实际 HTTP 状态码（宿主提供时）、模型、缓存命中率、Input / Output Token、TTFT、总耗时、TPS、估算美元。
- 汇总自加载或清空以来的请求总量、成功/错误/取消、Token 总量、平均 TTFT/耗时/TPS/缓存命中率、已知价格请求的美元合计及覆盖数。
- 日志为有界内存记录，汇总只保存聚合值，不不断累积文件；重载即清空。「清空请求日志」不取消正在运行的请求，也不删除最后一次鹈鹕结果。
- 页面可见时独立每 3 秒刷新活动数据，不额外轮询额度上游；未知指标显示 `—`，不伪造 0 或 HTTP 200，平均值只计已知样本。

### 统计口径

- **Input**：完整 prompt Token，包含缓存读写；不是直接把 pi-ai 的未缓存 input 当成总输入。
- **缓存命中率**：缓存读取 Token ÷ 完整 prompt Token。缺失缓存字段仅在累计用量能严格证明为 0 时才按 0；其他情况为未知。平均值是已知请求命中率的算术平均，不是整个账号按 Token 加权的命中率。
- **TTFT**：本地开始迭代请求流，到第一个非空文本、推理或工具调用 Token 增量。
- **总耗时**：从开始到终止事件或取消；**TPS** 为报告的输出 Token ÷ 首 Token 到结束的秒数，只有数据齐全且区间大于 0 才计算。输出含供应商报告的推理 Token；重复 usage 是累计快照，不重复相加。
- 上述均为**客户端观测值**，不是服务端精确解码指标。当前 DSH pi-ai 通常不透出 HTTP 响应码，因此成功请求的状态码也可能为 `—`；“成功/失败”和 HTTP 状态码是两个概念。不会从错误原文猜测状态码。

### 美元估算

按 [OpenAI 官方 Standard API 价目表](https://developers.openai.com/api/docs/pricing)及核实的模型页做静态快照，核对日期 **2026-11-08**；使用输入、缓存输入、输出对应单价，应用已支持模型的长上下文阶梯。只匹配明确核实的型号/日期快照，不按相似名字猜价格。

**这是 API 价格折算，不是 ChatGPT 订阅实际账单或额度扣费。** 不包含 Fast/Priority、Batch/Flex、地域加价、特殊合同、工具或图片等附加费用。未覆盖型号或用量不全时显示未知，并单列未估算请求数；未知不算成免费。

缓存计费细节不足但能可靠界定上限时显示 `≤`，而非伪装精确估算。例如部分新型号的缓存写入有不同保留时长价格，只有明确写入数量才能按已核实的较高档位计算上限；无法界定则未知。价目表更新需随插件维护，不后台下载、不产生价格缓存文件；部分有时效促销或未完整核实计费条件的型号暂不估算。

## 鹈鹕 SVG 测试（纯内存）

选择模型后可「立即测试一次」，或显式启用每 **1–10080 分钟**一次的计划。提示词固定为：

> 生成一张鹈鹕骑自行车的SVG

- 默认关闭，计划不持久化，插件重载后关闭。
- 保存启用后先等一个完整间隔才首次执行；完成后再等一个间隔，不并发堆积请求。
- 「取消当前」仅取消本次；「关闭定时」同时停止计划和当前测试。启用/执行会消耗真实模型额度。
- 直接调用宿主 LLM 服务，不创建会话、不使用工具或附件，**不生成 SVG、输出、日志或缓存文件**。仅保留内存中的最后一次结果，最多 256 KiB；单次包含模型验证在内最多 120 秒。
- 取消、停用及卸载会中止在途工作并拒绝迟到结果。SVG 仅以转义文本展示，绝不注入 HTML 或执行。是否生成 SVG 不等于图像质量评测。

纯内存限制针对鹈鹕功能本身，不等于阻止宿主正常刷新授权并保存凭据、第三方追踪插件独立记录、系统/浏览器行为或上游服务保留数据。本插件不会启用这些追踪，也不改宿主策略。

## Fast 开关兼容性

**Fast 位于周额度左侧**。本版明确显示“不支持”并禁用：核实过的 DSH `0.2.2-rc.1` 公开 Codex 适配器尚不透传 `service_tier`。不会做只改变 UI 的假开关，不替换全局网络请求，也不修改已安装的 DSH；真正生效需要宿主先提供支持。

## 额度与安全

额度是账号级最近观测值，不保证各模型有独立额度。授权由 DSH 凭据服务保管，浏览器不会收到令牌。写接口通过宿主鉴权和同源校验，响应使用 `Cache-Control: no-store`。

模型目录查询最低使用已验证的 Codex 兼容版本 `0.165.0`。若本机有 Codex 模型缓存，只读取其中较新的稳定 `client_version`；模型目录和授权仍来自当前 DSH 账号，不导入其他账号的模型、身份或凭据。未安装 Codex 也可使用插件内的兼容版本。
